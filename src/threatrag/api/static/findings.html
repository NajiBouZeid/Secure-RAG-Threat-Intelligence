ConsoleFindings

Everything below is read back from the evidence files committed in reports/data. Nothing on this page runs a model or queries the index, so it reports the same numbers whether or not the services are up. Where repeats of one cell disagree, both ends are shown and the cell is marked unstable rather than averaged into something steadier than the measurement was.

Attacks that landed

Seven attacks (m4) and two evasion variants, per defence set and model. Lower is better, and the result worth reading is the difference between the undefended row and the full set.

The retriever changes the security result

The same attacks and the same defences over three retrievers. Swapping the retriever re-scoped every defence, which is why a defence result only means something alongside the retriever it was measured on.

What the defences cost in answer quality

Each dot is one benchmark cell over 200 gold questions. The band is the range the undefended configuration produces when it is simply re-run. A defence has only been shown to cost something if it sits clear of that band.

What this does not settle

Kept on the same page as the results, because a result whose limits live somewhere else gets quoted without them.

  • No defence set's utility cost is resolved. The dots above overlap the baseline band — and so does an undefended control run in the same position. A cell that defends nothing reproduces the deficit the defended cells show, so the deficit is not evidence of a defence cost.
  • Answers at temperature 0 are not reproducible. A first generation inherits the cache left by whatever ran before it. Generating twice and keeping the second fixes that within a process and not across processes, so which cell ran first is a confound on any comparison.
  • One attack is a coin flip on the small model. Three repeats expose it without explaining it.
  • The two attack routes are not on one scale, and are deliberately not collapsed into a single security score.
  • Hybrid retrieval cannot be combined with corpus segregation as built: fusing the two collections would have to be done by rank, and it is done by score.

Full detail and the reasoning behind each: reports/m7_benchmark.md and reports/hybrid_retrieval.md.
